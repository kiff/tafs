# Release notes

What each Android release says in Google Play's "What's new", in English (the source) and the
seven other languages tafs speaks ([languages.md](languages.md)). Play takes up to 500 characters
per language. The same rules as [store-listing.md](store-listing.md): the glossary's words, the
same claims in every language, nothing stronger, and only what a person can see on screen.
