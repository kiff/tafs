# Japanese (`ja`)

**Name:** tafs

**Short description** (61 of 132 characters):

あなたのChromeでtafsが作業します。許可したサイトだけで動き、リスクのある操作はすべてスマートフォンで承認します。

**Long description:**

Chrome 版 tafs は、許可したサイトだけで、あなたの tafs があなた自身の Chrome で働けるようにします。危険な操作はすべて、スマートフォンで承認するまで待ちます。

• この Chrome をスマートフォンとペアリングします。tafs アプリでアカウント › Chrome › Chromeをペアリングを開き、表示されたコードを入力してください。
• taf は専用のタブ、見えるタブグループの中で働きます。サイドパネルからメッセージを送った taf は、今いるタブがそのサイトの一つなら代わりにそのタブで働き、ほかのページは自分のタブで開きます。いつでも一時停止や停止ができ、そのタブに触れると一時停止します。 作業中は、各ウィンドウの手前のページに小さなバーが表示され、一時停止、停止、そのタブへの移動ができます。バーはそのページから何も読み取りません。
• Chrome はインストール時に一度だけ、すべてのサイトへのアクセスを求めます。tafs が作業するのは、各タスクが挙げるサイトだけで、それはスマートフォンで承認します。
• 支払いと注文は、必ずスマートフォンでの承認を待ちます。
• ページはテキストと入力欄として読み取り、パスワード、カード、コードの欄は除きます。ほかのタブや履歴は読みません。
• taf はページ上のひとつの手順をあなたに任せることがあります。たとえば検索やカード番号の入力です。入力はあなた自身が行い、taf がページを読み直すときは、入力欄にあなたが入力した内容は除かれます。
• 銀行、ウォレット、パスワード管理、決済、健康、行政のサイトは扱いません。スマートフォンで 1 つの作業に限って許可した場合は例外です。
• パスワードを保存することはありません。サインインのページでは taf が止まり、あなた自身のタブであなたがサインインするよう求めます。
• サイドパネルには、この Chrome で作業する taf が表示され、tafs アプリと同じようにそこで話しかけられます。「このサイト用の新しいtafを設定」を押すと Coach が開き、専用の画面で表示されます。Coach にメッセージを送ると、手前のページを同じ欄を除いて読み取ります。銀行、決済、メール、健康のサイトとオフにしたサイトは読み取らず、メッセージの下に「読み取り:」とサイトを表示します。許可したあとだけで、自分のサイトにいる taf へのメッセージも同じです。ページなしで送ることもいつでもできます。
• 選んだファイルは、tafs アプリでの添付ファイルと同じように、tafs cloud と Claude に送られます。

taf が読んだ内容は、作業を実行する AI に渡され、その作業とともに保管されます。KIFF は変更の前後のページを最長 30 日間保管します。スクリーンショットを有効にすると、操作を行う各ステップは、操作の直前に撮影したページのスクリーンショットも1枚保管します。パスワード、カード、コードの欄は隠され、保管は最長 30 日間です。見られるのは tafs アプリ内だけで、AI には送られません。ペアリング解除やアンインストールで、拡張機能がこのコンピュータに保存した内容は削除されます。

スマートフォンの tafs アプリと KIFF アカウントが必要です。

プライバシーポリシー: https://kiff.dev/tafs/privacy
