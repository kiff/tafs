# Chinese (Traditional) (`zh-Hant`)

**Name:** tafs

**Short description** (53 of 132 characters):

讓您的 taf 在您自己的 Chrome 中工作，只限您允許的網站。每個有風險的步驟都會等您在手機上核准。

**Long description:**

Chrome 版 tafs 讓您的 taf 在您自己的 Chrome 中工作，只限您允許的網站。每個有風險的步驟都會等您在手機上核准。

• 將這個 Chrome 與您的手機配對：在 tafs 應用程式中開啟「帳號 › Chrome › 配對 Chrome」，然後輸入顯示的代碼。
• taf 在它自己的分頁中工作，位於您看得到的分頁群組內。您可隨時暫停或停止，碰到它的分頁時它會暫停。 它工作時，每個視窗最前方的頁面上會有一條小橫列，讓您暫停、停止或前往它的分頁。這條橫列不會讀取該頁面的任何內容。
• Chrome 會在安裝時一次詢問所有網站的存取權。tafs 只會在每項任務列出的網站上作業，而這些網站由您在手機上核准。
• 付款和下單，一律等您在手機上核准。
• 它以文字和表單欄位讀取頁面，並移除密碼、卡片和代碼欄位。它絕不讀取您的其他分頁或瀏覽記錄。
• taf 可以把頁面上的一個步驟交給您，例如輸入搜尋字詞或卡號。由您自己完成，它重新讀取頁面時，會略過您在欄位中輸入的內容。
• 銀行、錢包、密碼管理工具、付款、健康和政府網站絕不處理，除非您在手機上為單一任務允許其中一個。
• 它絕不保存您的密碼。遇到登入頁面時，taf 會停下來，請您在自己的分頁中自行登入。
• 側邊面板會顯示在這個 Chrome 中作業的 taf，您可以像在 tafs 應用程式中一樣在那裡與它交談。「為這個網站設定新的 taf」會開啟 Coach，並以獨立畫面顯示。您傳訊息給 Coach 時，它會讀取最前方的頁面並移除相同的欄位；銀行、付款、郵件或健康網站，以及您關閉的網站除外。您的訊息下方會顯示「讀取：」和網站。

taf 讀到的內容會交給執行您任務的 AI，並與該任務一併保存。KIFF 最多保存變更前後的頁面 30 天。啟用螢幕截圖後，每個執行動作的步驟還會保存一張頁面截圖，於動作前一刻拍攝，並隱藏密碼、卡片和代碼欄位，最多保存 30 天。您只能在 tafs 應用程式中看到，且它絕不會送給 AI。取消配對或解除安裝會刪除擴充功能保存在您電腦上的內容。

您需要手機上的 tafs 應用程式和一個 KIFF 帳戶。
