# Chinese (Traditional) (`zh-Hant`)

**Name:** tafs

**Short description** (53 of 132 characters):

讓您的 taf 在您自己的 Chrome 中工作，只限您允許的網站。每個有風險的步驟都會等您在手機上核准。

**Long description:**

Chrome 版 tafs 讓您的 taf 在您自己的 Chrome 中工作，只限您允許的網站。每個有風險的步驟都會等您在手機上核准。

• 將這個 Chrome 與您的手機配對：在 tafs 應用程式中開啟「帳號 › Chrome › 配對 Chrome」，然後輸入顯示的代碼。
• taf 在它自己的分頁中工作，位於您看得到的分頁群組內。您可隨時暫停或停止，碰到它的分頁時它會暫停。
• 在您於 Chrome 中允許之前，tafs 不能使用任何網站；任務需要時，一次允許一個網站。
• 付款、下單和填入已儲存的登入資料，一律等您在手機上核准。
• 它以文字和表單欄位讀取頁面，並移除密碼、卡片和代碼欄位。它絕不讀取您的其他分頁或瀏覽記錄，也不截圖。
• 銀行、錢包、密碼管理工具、付款、健康和政府網站絕不處理，除非您在手機上為單一任務允許其中一個。
• 已儲存的登入資料為選用，並封存在這台電腦上。tafs 和 KIFF 絕不會看到。
• 在側邊面板與 Coach 交談。只有當您按下「分享此頁面」時，Coach 才會看到頁面，而且只看該頁，並移除相同的欄位。

taf 讀到的內容會交給執行您任務的 AI，並與該任務一併保存。KIFF 最多保存變更前後的頁面 30 天。取消配對或解除安裝會刪除擴充功能保存在您電腦上的內容。

您需要手機上的 tafs 應用程式和一個 KIFF 帳戶。
