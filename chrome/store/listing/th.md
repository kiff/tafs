# Thai (`th`)

**Name:** tafs

**Short description** (116 of 132 characters):

ให้ taf ของคุณทำงานใน Chrome ของคุณเอง เฉพาะบนเว็บไซต์ที่คุณอนุญาต ทุกขั้นตอนที่เสี่ยงจะรอการอนุมัติของคุณบนโทรศัพท์

**Long description:**

tafs สำหรับ Chrome ให้ taf ของคุณทำงานใน Chrome ของคุณเอง เฉพาะบนเว็บไซต์ที่คุณอนุญาต ทุกขั้นตอนที่เสี่ยงจะรอการอนุมัติของคุณบนโทรศัพท์

• จับคู่ Chrome นี้กับโทรศัพท์ของคุณ: ในแอป tafs เปิด บัญชี › Chrome › จับคู่ Chrome แล้วพิมพ์รหัสที่แสดง
• taf ทำงานในแท็บของตัวเอง ในกลุ่มแท็บที่คุณมองเห็น taf ที่คุณส่งข้อความถึงจากแผงด้านข้าง ทำงานในแท็บที่คุณเปิดอยู่แทนได้ หากเป็นเว็บไซต์หนึ่งของมัน และเปิดหน้าอื่นในแท็บของมันเอง ในแท็บที่คุณเปิดอยู่ taf คลิกและพิมพ์ได้ เฉพาะบนเว็บไซต์ของมันเอง คุณหยุดชั่วคราวหรือหยุดได้ทุกเมื่อ และมันจะหยุดชั่วคราวเมื่อคุณแตะแท็บใดแท็บหนึ่งของมัน ระหว่างที่ทำงาน ขอบแท็บของมันจะเรืองแสง แถบด้านบนบอกว่า taf ตัวไหนกำลังทำงานอยู่ที่นั่น และให้คุณหยุดชั่วคราวหรือหยุดมันได้ และตัวชี้จะชี้ช่องหรือปุ่มแต่ละอันก่อนที่ taf จะทำอะไรกับมัน ตัวชี้นี้เป็นเพียงภาพวาด ไม่มีเมาส์จริงขยับ ในแท็บอื่นๆ ของคุณ แถบเล็กๆ ให้คุณหยุดชั่วคราว หยุด หรือไปที่แท็บของมันได้ และแถบนี้ไม่อ่านอะไรจากหน้านั้น
• Chrome จะขอสิทธิ์เข้าถึงทุกเว็บไซต์เพียงครั้งเดียวตอนติดตั้ง tafs ทำงานเฉพาะบนเว็บไซต์ที่แต่ละงานระบุ ซึ่งคุณอนุมัติบนโทรศัพท์
• การจ่ายเงินและการสั่งซื้อ จะรอการอนุมัติของคุณบนโทรศัพท์เสมอ taf จะไม่ส่งเงินออกเอง (การคืนเงิน การจ่ายออก หรือการโอน) อย่างมากก็ขอให้คุณทำเอง
• มันอ่านหน้าเว็บเป็นข้อความและช่องฟอร์ม โดยตัดช่องรหัสผ่าน บัตร และรหัสออก ไม่เคยอ่านแท็บอื่นหรือประวัติของคุณ
• taf ส่งต่อขั้นตอนหนึ่งบนหน้าเว็บให้คุณทำได้ เช่น พิมพ์คำค้นหาหรือหมายเลขบัตร คุณทำเอง และเมื่อมันอ่านหน้านั้นอีกครั้ง สิ่งที่คุณพิมพ์ในช่องจะถูกตัดออก
• เว็บไซต์ของธนาคาร กระเป๋าเงิน ตัวจัดการรหัสผ่าน การชำระเงิน แดชบอร์ดผู้ขาย สุขภาพ และหน่วยงานรัฐ จะไม่ถูกใช้ทำงานเลย เว้นแต่คุณอนุญาตเว็บหนึ่งสำหรับงานหนึ่งบนโทรศัพท์ taf จะไม่เปิดเว็บไซต์ของ KIFF เอง
• ไม่เคยเก็บรหัสผ่านของคุณ ที่หน้าลงชื่อเข้าใช้ taf จะหยุดและขอให้คุณลงชื่อเข้าใช้เองในแท็บของคุณ
• แถบด้านข้างแสดง taf ที่ทำงานใน Chrome นี้ และคุณคุยกับมันที่นั่นได้ เหมือนในแอป tafs “ตั้งค่า taf ใหม่สำหรับเว็บไซต์นี้” จะเปิด Coach ในมุมมองของตัวเอง เมื่อคุณส่งข้อความถึง Coach มันจะอ่านหน้าที่อยู่ด้านหน้าโดยลบช่องเดิมออก ยกเว้นเว็บไซต์ธนาคาร การชำระเงิน อีเมล หรือสุขภาพ และเว็บไซต์ที่คุณปิดไว้ และแสดง “กำลังอ่าน:” กับชื่อเว็บไซต์ใต้ข้อความของคุณ เฉพาะหลังจากคุณอนุญาต และเช่นเดียวกันสำหรับข้อความถึง taf บนเว็บไซต์หนึ่งของมัน คุณส่งโดยไม่มีหน้าได้เสมอ
• ไฟล์ที่คุณเลือกจะไปที่ tafs cloud และ Claude เหมือนไฟล์แนบในแอป tafs

สิ่งที่ taf อ่านจะส่งไปยัง AI ที่ทำงานของคุณ และเก็บไว้กับงานนั้น KIFF เก็บหน้าเว็บก่อนและหลังการเปลี่ยนแปลงไม่เกิน 30 วัน เมื่อเปิดใช้การจับภาพหน้าจอ ทุกขั้นตอนที่ดำเนินการจะเก็บภาพหน้าจอของหน้าเว็บหนึ่งภาพด้วย โดยถ่ายก่อนดำเนินการและซ่อนช่องรหัสผ่าน บัตร และรหัสไว้ เก็บไม่เกิน 30 วัน คุณเห็นภาพนี้ได้เฉพาะในแอป tafs และจะไม่ถูกส่งไปยัง AI การเลิกจับคู่หรือถอนการติดตั้งจะลบสิ่งที่ส่วนขยายเก็บไว้บนคอมพิวเตอร์ของคุณ
