# German (`de`)

**Name:** tafs

**Short description** (125 of 132 characters):

Lass deine tafs in deinem Chrome arbeiten, nur auf Websites, die du erlaubst. Jeden riskanten Schritt genehmigst du am Handy.

**Long description:**

tafs für Chrome lässt deine tafs in deinem eigenen Chrome arbeiten, nur auf den Seiten, die du erlaubst. Jeder riskante Schritt wartet auf deine Genehmigung auf deinem Handy.

• Verbinde dieses Chrome mit deinem Handy: Öffne in der tafs-App Konto › Chrome › Chrome koppeln und gib den angezeigten Code ein.
• Ein taf arbeitet in eigenen Tabs, in einer Tab-Gruppe, die du sehen kannst. Du kannst es jederzeit pausieren oder stoppen, und es pausiert, wenn du einen seiner Tabs berührst.
• tafs kann eine Seite erst nutzen, wenn du sie in Chrome erlaubst, Seite für Seite, wenn eine Aufgabe sie braucht.
• Bezahlen, eine Bestellung aufgeben und eine gespeicherte Anmeldung ausfüllen warten immer auf deine Genehmigung auf deinem Handy.
• Es liest eine Seite als Text und Formularfelder, ohne Passwort-, Karten- und Code-Felder. Es liest nie deine anderen Tabs oder deinen Verlauf und macht keine Screenshots.
• Banken, Wallets, Passwortmanager, Zahlungen, Gesundheits- und Behördenseiten werden nie bearbeitet, es sei denn, du erlaubst eine für eine Aufgabe auf deinem Handy.
• Gespeicherte Anmeldungen sind optional und auf diesem Computer versiegelt. tafs und KIFF sehen sie nie.
• Sprich in der Seitenleiste mit Coach. Coach sieht eine Seite nur, wenn du auf Diese Seite teilen klickst, und dann nur diese Seite, mit denselben entfernten Feldern.

Was ein taf liest, geht an die KI, die deine Aufgabe ausführt, und wird mit dieser Aufgabe aufbewahrt. KIFF bewahrt die Seite vor und nach einer Änderung höchstens 30 Tage auf. Beim Trennen oder Deinstallieren wird gelöscht, was die Erweiterung auf deinem Computer aufbewahrt.

Du brauchst die tafs-App auf deinem Handy und ein KIFF-Konto.
