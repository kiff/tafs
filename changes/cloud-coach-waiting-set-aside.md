- **tafs cloud: waiting Coach chats are named, and can be set aside.** Each row in Needs you says which chat it is, what Coach waits for and since when. Set aside one, or all of them at once, as "not now": nothing is approved or sent, the chat ends, and a connection it asked for that no taf uses is withdrawn. A chat left waiting ends on its own after 48 hours, or when its taf is replaced or removed (docs/api.md).
