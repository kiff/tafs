- **Sign in with a code sent by email, as a setting in the apps (iPhone, iPad, Mac and Android).** Account › Sign-in shows whether it is on, turns it off at once, and opens KIFF's sign-in page to turn it on (the page asks you to confirm it's you). It is off for everyone until they turn it on ([docs/ios-app.md](docs/ios-app.md), [docs/android-app.md](docs/android-app.md)).
- **The Chrome pairing code has a Copy button on iPhone, iPad and Android.** It stays on the clipboard for a few minutes on iPhone and iPad, and a minute on Android (marked sensitive, so the system's preview never shows it), so a code left there lapses with it ([docs/chrome.md](docs/chrome.md), [docs/android-app.md](docs/android-app.md)).
- **Chrome's pairing field takes the whole code.** The side panel's code field held 13 characters, so a pasted or typed code (21 characters, 26 with its dashes) was cut off. It now holds a whole code, with its dashes or spaces, in any case ([docs/chrome.md](docs/chrome.md)).
- **The Chrome extension has the tafs icon** in its toolbar, on its extensions page and in the Web Store listing (16, 32, 48 and 128 pixels, from the app icon), and it is pinned to planque's key and relay, so a code typed into it pairs ([docs/chrome.md](docs/chrome.md)).
