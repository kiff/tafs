- **A taf's new version uses its own new connection (tafs cloud).** When an improvement brought a fresh Qonto sign-in for more access, Coach kept the old connection's tools on the version's Card and only added the new one. The version's trial then kept reading through the old connection, and the new one was never called. Coach now names the new connection's tools on every Card for that app in the version (`improve-a-taf@6`). tafs cloud also refuses to switch to a version whose Card names tools of two connections to the same app, so such a version never goes live.
