- **A taf's new version uses its own new connection (tafs cloud).** When an improvement brought a fresh Qonto sign-in for more access, Coach kept the old connection's tools on the version's Card and only added the new one. The version's trial then kept reading through the old connection, and the new one was never called. Coach now names the new connection's tools on every Card for that app in the version (`improve-a-taf@6`). Before the owner confirms a version, tafs cloud also refuses one that brings in a new connection to an app while its Card still names the connection in use. A taf meant to use one app through two connections keeps both.
