- **A taf's new version uses its own new connection (tafs cloud).** When an improvement brought a fresh Qonto sign-in for more access, Coach kept the old connection's tools on the version's Card and only added the new one. The version's trial then kept reading through the old connection, and the new one was never called. Before the owner confirms a version, tafs cloud now refuses one that brings in a new connection to an app beside the connection in use, and Coach asks the owner whether it replaces that one or is another account (`improve-a-taf@6`). Replacing it, every Card for that app names the new connection's tools. Another account, such as a second inbox, keeps both: the version records it for that app, and its switch goes through. A taf meant to use one app through two connections already in use keeps both.
