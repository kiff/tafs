- **tafs cloud: work can pass through three tafs, and a taf can say it has nothing to hand over.** A taf that got its work from another taf can now hand its own result on once more: twice at most, and never back to a taf that already had it, so nothing circles. A third hand-off is refused and said on the request. A taf with nothing for the next one writes "Nothing to hand over" and why, and the request reads "Nothing to hand to Invoices: …" instead of looking broken. The taf that receives a hand-off is told to read what it names as it is now before it changes anything. When a receiving taf only passed the work on, the first taf's request says where it went (docs/reliability.md).
