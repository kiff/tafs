- **How a taf uses websites, the two ways (tafs cloud).** Connect apps now lists the cloud browser and the Chrome extension, each with what it does and its two facts, even before the account connects either one. Chrome's entry names the Chrome it's paired with. Each browser connection in a taf's setup says its way, its sites and its paired Chrome. A taf that browses has a `browsing` section with the other way's button, which opens Coach with the change written in.
- **A saved sign-in in the cloud browser says how it's holding, and a run it can't do waits for the owner (tafs cloud).** Each site of a cloud browser connection, on the taf's setup and in Connect apps' saved sign-ins, says whether its saved sign-in held at planque's last check: signed in, needs you by a day, stopped, or not checked. A scheduled taf's schedule names its connection, so the scheduler checks the sign-in before a run and holds the run, rather than run it and fail, when the site asked to sign in again. Home lists the held run (Sign in again, Skip this run) and a sign-in that ends within 3 days (Sign in again, Later), each once in Needs you. The taf's work page lists the held run with the others that didn't start.
