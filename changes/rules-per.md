- **An agreed rule can name a total for each item (tafs cloud).** A rules notice's figure may carry `per` ("one invoice per order, ever"), in any of an aggregate's windows. Approve then holds the Cards to it like any other figure: each per total on that tool must match an agreed `(quantity, window, per)`, or it's refused. On a rule that names no per total, per totals stay with the earlier checks until `TAFS_RULES_PER=on`, which is switched once Coach's rules carry them (docs/coach.md).
