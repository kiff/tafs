- **The iPhone's app map.** A UI test opens every route of app/routes.json in the sample, through a debug-only hook (`-routeWalk YES`), and writes what each did (opened, title shown, or why it was refused) as app/map/ios.json; it fails when a route that opens doesn't show its title, or when the map changes and the file wasn't updated. It runs in CI with the iPhone's UI tests, and beside the unit tests when the routes or AppModel change (docs/ios-app.md).
