- **iPhone, iPad and Mac alerts no longer fail as "too many token updates" (tafs cloud).** Apple refused every push with `429 TooManyProviderTokenUpdates` when each tafs cloud instance made its own provider token. Now one token, kept in the table, serves every instance until it's 40 minutes old, then one instance replaces it; pushes sent together share it, and a push Apple refuses that way is sent once more with the shared token (docs/approvals.md). No app release is needed.
