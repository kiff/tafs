- **iPhone and iPad: sign-in no longer waits on Face ID.** The "Set up approvals on this device" screen no longer comes before sign-in. Approvals are set up at Coach's Start. A phone that signed in before Face ID was set up gives KIFF its approval key under Start's one Face ID. If KIFF doesn't accept it, Start sends nothing and says "KIFF didn't accept this phone's approval key. Try again." From the second time, it also says where to write. Both apps share the line in all 8 languages. Android does the same since 1.20 (docs/approvals.md › On iPhone and iPad).
