- **A fixed taf no longer reads as failing (tafs cloud).** A taf's health puts its latest run first: when the newest run worked, the failures before it stop counting toward "2 of its last 3 runs failed", so a taf that was fixed reads healthy at once, in both apps. The failures stay in its runs list. Its next failure brings them back, and three failures in a row still say so (docs/reliability.md).
