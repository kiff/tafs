- **Android:** pairing a Chrome when one is already paired asks which it replaces, starting on the same Chrome. Only the connections this phone signed for the old Chrome move to the new one, checked with its own key, and the old one is unpaired. Account › Chrome says what each Chrome is used for, and Unpair says which connections it ends. Where the extension supports it, one fingerprint pairs it ([docs/android-app.md](../docs/android-app.md), "Pairing a Chrome").
