- **A taf answers "what did you do today" from a record that covers the day (tafs cloud).** A chat shows only what was done in it, and a quiet chat is followed by a new one, so a taf asked in a new chat what it had refunded today said the day's refunds had gone through "by other means". Every taf is now told to answer a question about a time from its Card's use (kiff_card) or the app's own list, to say which it read, and never to put work it can't see in this chat down to someone else. Each taf's definition changes, so the upgrade rewrites them. See [A taf's chat](docs/chat.md).
