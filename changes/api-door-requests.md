- **A door From another application: the caller's routes (off):** behind `TAFS_API_DOORS`, another application submits a request with the door's key and an `Idempotency-Key`, and reads how it went. Its input is checked against the door's fields. It's admitted only when the door is open, the taf isn't halted and the limits allow (10 a minute, 100 a day, 20 waiting). Requests start one at a time from a fixed, fenced template, and the answer is the door's outcome with the record's count of calls ([doors.md](docs/doors.md)).
