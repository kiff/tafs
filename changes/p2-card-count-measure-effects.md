- **A taf's day total of calls is drafted with `measure: effects`, so a call that did nothing doesn't use the day's room** (`draft-the-card@43`; [coach.md](docs/coach.md)). A Gmail send refused by Gmail (nothing sent) used the Card's only call of the day, and a held retry then needed extra room (phone test, 21 Nov 2026). An attempts total never gives a call back; an effects total does when KIFF has trusted evidence the call had no effect. Money tools' amount limits are unchanged. Whether a given refusal counts as no effect is planque's and the gateway's rule (separate changes); this changes only how Coach drafts the total.
