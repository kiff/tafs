- **Removing a taf ends the apps only it used (tafs cloud).** After its key, tafs cloud ends the taf's connections in any status, a waiting or failed one included, with the person's own session. A sign-in another taf still uses stays. A removal the connection server couldn't finish stops there, and asking again goes on. `GET /v1/tafs/{id}/removal` gives the confirmation's words before the fingerprint, in 8 languages: "Qonto goes with it. Stripe stays: Chargebacks uses it." Until the connection server has the route, removals go on as before, with the apps' own disconnect (docs/api.md).
