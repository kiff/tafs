- **tafs cloud: a connection from Connect apps goes only to a taf that uses the app.** Each app lists the tafs that need it (`needed_by`: their recipe, or their Card) and, with the phone's signed read, a connection made under the wrong taf (`misplaced`), so it can be withdrawn. Starting one for any other taf is refused (`not_needed`), so no app picks a taf just because it's the only one ([api.md](../docs/api.md)).
