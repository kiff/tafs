- **A taf set up for one form keeps the form's id (tafs cloud).** When a taf's job names one form, sheet, folder or board, Coach finds its id during setup, from the connection's list by name, or asks the owner which one or for its link, and hands it over in the result's `sources` (`{kind, name, id}`). The taf's definition lists each by id, so its first run reads it without asking. tafs cloud refuses a source with no id, an id that only stands for one, and a job that leaves an id to fill in (`[form ID]`), in words that send Coach back to find it. Before, a taf set up for a named form could start without its id, and its first run asked the owner for it (Coach's `set-up-a-taf@16`, docs/coach.md).
