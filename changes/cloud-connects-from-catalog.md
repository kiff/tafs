- **Which apps connect today can come from planque's catalog (tafs cloud, off by default).** With `TAFS_PROVED_FROM_CATALOG=on`, `GET /v1/recipes` and the gallery list the jobs whose apps planque's catalog marks `proved`, instead of the list in tafs cloud's code. A catalog that can't be read, or marks none, keeps the list. Nothing changes until the flag is turned on, once kiff.dev reads the same mark (docs/coach.md).
