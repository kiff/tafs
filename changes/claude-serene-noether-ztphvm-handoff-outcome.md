- **A taf that hands its result to another taf now shows what became of it (tafs cloud).** "Handed to Invoices" only said the other taf's run had started. The sending taf's request now says how that run ended: done, waiting for you, nothing was done, or that it finished. When the receiving run failed, was stopped or never started, the request goes to Needs you ("Invoices didn't finish what Rae handed it") with **Send again**, and the people who manage the sending taf get one note. A run that failed after it had already acted isn't offered Send again, so nothing is done twice. The receiving request says which taf handed it its work. The apps draw tafs cloud's lines, so no app release is needed (docs/reliability.md).
