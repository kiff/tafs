- **Android 1.13: a secure sheet for an app's key.** The key sheet now says who it connects to, with the app's logo and a lock, what the connection may do, that the key is sealed, and that it can be disconnected any time. The key is pasted with one button, never typed: only its last 4 characters show, and the clipboard is cleared. The technical lines sit under Details. After connecting, a receipt shows the key's last 4 and Disconnect. An approval whose connection is already done no longer repeats it.
