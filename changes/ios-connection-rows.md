- **iPhone and iPad: readable connections, with a detail before any action.** Each connection in an app's list says what it is, which tafs use it and how it's doing ("Working · last used 00:32", "Gmail's sign-in expired on 14 Nov"), in the connection service's words. Tapping one opens its detail with only the actions that can work; Remove access is there, says what stops, and asks once more. An unfinished leftover offers only its removal, never Sign in again (docs/ios-app.md).
