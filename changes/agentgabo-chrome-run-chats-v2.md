- **The Chrome side panel shows a run that worked in that Chrome, even when its message was sent from the phone.** It shows only that run's turn: the message that started it, its steps and its answer. The panel can read it and report an answer, never write into it. It leaves the panel when the chat is deleted or the Chrome is unpaired. A Chrome paired before this shows such runs once it's paired again. See [Chrome](docs/chrome.md).
