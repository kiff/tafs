- **A taf's check is handed over only if its list is where Coach's reads found one.** When Coach hands over a new taf whose check names a list (`items`) that none of the reads Coach made in that conversation has, tafs cloud answers Coach with the lists those reads do have, and makes nothing, so Coach fixes the check before the taf's first check fails. With no read that answered JSON, the hand-over goes on as before. A refused connection whose reason scrubbed to nothing is still logged ([Coach](../docs/coach.md)).
