- **iPhone and iPad: tafs cloud's lines, as Android draws them.** The next run says its day when it isn't today ("Next run Mon 08:00"), on the home list, the taf's runs and Setup, in tafs cloud's words. A taf whose last check, health or run went wrong says so in place of its next run, without the Working chip. Its runs list the firings that started no run, a failed Run now among them. A taf's Cards keep tafs cloud's order, so the one in use is in front. The Record shows an action's whole title with its amount ("Save a dispute response · $800"), never "Save $800" (docs/ios-app.md).
