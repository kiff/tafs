- **Chrome 0.2.10: files on a message from the side panel, as in the apps (tafs cloud and the extension).** The **+** in the composer opens Chrome's file picker; each file shows as a chip above the box until Send, with × to remove it, and goes with the message to Coach or to a taf. The same types and limits as the apps (photos 10 MB, PDF 25 MB, text, CSV, Markdown, Word and Excel 2 MB, at most 5), every image redrawn as a JPEG so no metadata goes, and its bytes uploaded straight to storage. tafs cloud now takes files from a Chrome as from the apps, and a Chrome still never reads one back. No microphone. The store listing and privacy practices say files go to tafs cloud and Claude, like attachments in the apps (docs/chrome.md, "Files on a message").
