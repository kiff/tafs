- **A removal never reads as clean with its connections still live.** When the connection server can't end a removed taf's connections because it has no route for it, `DELETE /v1/tafs/{id}` now lists `connections` in `failed`, and the removal stops there, as it does when the server is down. Before, it was left out and the removal answered `done: true`. The apps no longer end the connections themselves, so both apps now name the step that's left, with no code of their own.
