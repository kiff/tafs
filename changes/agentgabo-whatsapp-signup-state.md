- **WhatsApp's signup gives back the app's one-use `state`.** An app may open `GET /doors/whatsapp/connect` with `state` (16 to 64 letters, digits, `-` or `_`), and the return to `tafs://doors/whatsapp` carries it unchanged, so an app whose `tafs://` link any page can open takes only the return of the signup it started. A malformed `state` opens no page; without one, nothing changes ([doors.md](docs/doors.md)).
