- **Android: "A new Card" shows each Card's limits after its own tool.** A draft's new Cards show together, and a line seen on an earlier Card used to be dropped. A Card's total names no tool ("20 calls a day"), so with two new Cards that had the same total, the second tool read as unlimited just before the fingerprint. Now each Card's lines stay together, and only a whole Card exactly like an earlier one shows once. What is signed is unchanged. See docs/android-app.md.
