- **Android: pair a computer from Devices.** Account → Devices → Add a computer scans the computer's QR, asks whether the computer shows the same 6-character check code, and on yes signs the pairing to KIFF with the approval key, behind a fingerprint that names the computer. KIFF decides whether it's paired; the computer is then listed with Sign out. Signing another device out is now signed by the approval key behind one fingerprint, never inside an approval window, as KIFF will require for a device that can approve. Coach can't start or confirm a pairing (docs/android-app.md, Pairing a computer).
