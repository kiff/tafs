- **What a taf works from lives in its version, never in one chat (tafs cloud).** When the owner gives a taf a folder or a sheet in its chat, the taf uses it for that request and offers Coach's "add it to the setup". Coach makes the next version with those sources, each by id (`improve-a-taf@5`). Once the owner installs it, every run has them, from a door and a schedule too, and going back to an earlier version brings back what that version had. Before this, links given in the owner's chat never reached a door run, which then had to ask again.
