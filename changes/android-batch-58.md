- **Android 1.8.2: a taf's row and runs in tafs cloud's words; Record titles whole; a newer version offered.** A taf's next run reads with its day ("Next run Mon 08:00"), as tafs cloud writes it, and a failed check, an unhealthy taf or a stopped run shows its line instead of "Working". Its Cards keep tafs cloud's order, the one nearest its limit first. Its runs list a Run now whose check couldn't read. The Record keeps an action's title whole with its amount after it ("Save a dispute response · US$800"), never "Save US$800" The Record's Search puts the keyboard away. When Play has a newer tafs, Home offers it in one line: Update, then Restart once it's downloaded (docs/android-app.md › A taf's work, A newer version). Remove for good asks for the fingerprint every time, removes only the taf its dialog named, and removes nothing if Home changes under the dialog or a tap lands the moment it opens. The removal is signed by the approval key, so tafs cloud can check it (docs/tafs.md).
