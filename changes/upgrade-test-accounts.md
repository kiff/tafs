- **The Upgrade can run for the test accounts only.** `upgrade.yml`'s `test_accounts_only` upgrades only the accounts listed in the `UPGRADE_TEST_TENANTS` secret (never in the public log, which prints their count), and may do so before an Eval measured the definitions.
