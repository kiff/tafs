- **tafs cloud: a scheduled check that keeps failing reaches the owner.** Its lines say when, and name the app it reads by its connection's name ("The 09:00 check couldn't read Gmail"). After 2 failed checks in a row, counted across a version switch, the taf is an urgent decision in Your brief, with "Open the taf", until a check reads again (docs/reliability.md, docs/missions.md).
- **tafs cloud: a failing check's alert says it was the check.** A check that couldn't read the app is no longer called "a run that couldn't start". A lone failure already alerted after six hours alerts once more when the next firing fails too, so a second failure in a row is never silent (docs/approvals.md).
