- **iPhone and iPad: a held call's Details writes every argument out in full.** A list or object (such as a held browser call's `steps`) was shown as "…"; now each item and field is written out, indented, keys in order, as `contracts/held-arguments.json` says every app does, so the owner reads every step before approving. A number shows every digit the taf sent, read from KIFF's own bytes rather than through a `Double`; one longer than 100 digits shows as sent (`1e400`).
