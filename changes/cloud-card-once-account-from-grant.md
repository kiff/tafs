- **Coach drafts a taf's Card once, and pins the account from the connection.** Coach's draft-the-card (version 17) drafts the Card once, after reading the fields, with all the taf's tools, never a first Card for reads alone; name-the-tools (version 13) pins the account the connection has, never a read of the accounts, and never asks for a read alone: a vendor's own server gets its describing tool with the sign-in. So a new taf takes one approval for the app and one for its Card ([Coach](../docs/coach.md)).
