- **A job in the gallery can carry a step-by-step guide (tafs cloud).** Each recipe file takes a `guide:` field, one to six steps with Do, You see and If lines, translated like the sample report, and the gallery serves it as `guide` next to `proved` and `sample`, with the heading and the three labels in all languages as `labels.guide`, `guide_do`, `guide_see` and `guide_if`. A job without a proof run has no guide. The apps draw it under the sample as "How it goes"; no job has one yet (recipes/README.md).
