- **Each run on a taf's page says what it used.** Every request in `GET /v1/tafs/{id}/work` carries `credits: {credits, counted, words}` from KIFF's usage record: the counted credits ("34 credits"), or why a run used none (a failed run, a trial). It's ready to draw, so both apps show the same number as the Credits page. A run KIFF hasn't counted yet, or a record that can't be read, has no line rather than a guess (docs/api.md).
